# --------------------------------------------------------------------------- #
#    ads_sets.txt                                                             #
#                                                                             #
#    The set of each public header of include/ADS, the only list of them:     #
#    cmake/ads_sets.py writes from it the entry points ADS/core.h,            #
#    ADS/base.h, ADS/advanced.h and ADS/ADS.h and the table of the README,    #
#    cmake/ads_module_exports.py the modules ads.core, ads.base, ads.advanced #
#    and ads, and manual/build/structmap.py the column of the sets of Table   #
#    1.5 of the manual. The sets are                                          #
#      - base, the structures and the algorithms that follow a textbook or    #
#        an academic source (Montresor, TAOCP, Ferragina's book and notes,    #
#        Morin), written to be read, even when they are fast;                 #
#      - advanced, those written for speed beyond those sources, the          #
#        concurrent and parallel structures, the executors, the distributed   #
#        layer, the typed modifications and the observers;                    #
#      - core, the infrastructure that the two include;                       #
#      - interop, the interoperation with other libraries (interop/), in      #
#        no entry point and no module: a program includes each of them        #
#        next to the headers of the other library;                            #
#      - both, the headers with a part of each set, until it is split off.    #
#                                                                             #
#    A line "<header> <set> [?<macro>] [<reason>]" gives the set of a header  #
#    (relative to include/ADS), the macro without which the header declares   #
#    nothing (the optional executors) and the reason of a borderline case;    #
#    an indented line goes on with the reason of the line above. A line       #
#    "<header> uses <header>" allows a header of core to include one of base, #
#    advanced or both, or one of base or both to include one of advanced,     #
#    which is otherwise an error of ads_sets.py: the entry point of the set   #
#    then pulls that header, without exporting its names from the module.     #
#    A header of advanced includes those of base freely, since it extends     #
#    them, and one of interop includes any other; no other set includes       #
#    one of interop. A new header is added here before anything else is run.  #
# --------------------------------------------------------------------------- #
