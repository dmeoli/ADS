# Benchmark results

The files of this folder are written by [`bench/run.sh`](../bench/run.sh),
one per run, with a header that records the machine, the compiler, the
load and the date; the tables below are those of the first of the two runs
summarized at the top of the [README](../README.md#performance), turned
into Markdown by [`bench/tables.py`](../bench/tables.py), while
[`bench/summary.py`](../bench/summary.py) gives the summary from both. In
each table a row is a structure and a column a case and a size $n$; a cell
is the time in nanoseconds per item for the sorts, the sequences and the
FFT, and per operation for the other structures, the median of 11 runs,
and in
parentheses its ratio to the first row of the table, which is the
structure of the standard library, or that of ADS where the standard
library has none. A row "A/A" is the first structure run a second time,
and its difference from the first row is the noise of the machine. The
load of 2.00 at the start is that of the compilation of the benchmarks,
which had just ended; the line `fft` records that the benchmark of the
FFT was run again after FFTW was rebuilt with its SIMD kernels, the
first build having none.

- runs: 11
